A one-line joke about office life. An AI agent drafts several lines, scores them by the brief, and writes
the winner to `/output/entry.txt`. It ships:

> My calendar is just back-to-back meetings titled 'quick sync' that could've been a message, from a man who could've been a message.

## Run it

```sh
python3 main.py
```
